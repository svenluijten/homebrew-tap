# homebrew-tap

This is a [Homebrew](https://brew.sh) tap for [snoei](https://github.com/svenluijten/snoei) and other tools by Sven Luijten.

## Install

Install snoei with one command:

```sh
brew install svenluijten/tap/snoei
```

Or add the tap first, then install by name:

```sh
brew tap svenluijten/tap
brew install snoei
```

## Update

```sh
brew upgrade snoei
```

## How this tap is maintained

The casks in this repository are generated by [GoReleaser](https://goreleaser.com) when a tool publishes a new release. Do not edit them here, because the next release will overwrite your changes. Open issues and pull requests in the tool's own repository instead, for example [svenluijten/snoei](https://github.com/svenluijten/snoei).
