# homebrew-tap

This is a [Homebrew](https://brew.sh) tap for tools by Sven Luijten.

## Available tools

| Tool | Description |
| --- | --- |
| [snoei](https://github.com/svenluijten/snoei) | Prune local git branches (and their worktrees) that are no longer on the remote. |

## Install

Install a tool with one command:

```sh
brew install svenluijten/tap/<tool>
```

Or add the tap first, then install by name:

```sh
brew tap svenluijten/tap
brew install <tool>
```

## Update

```sh
brew upgrade <tool>
```

## How this tap is maintained

The casks in this repository are generated by [GoReleaser](https://goreleaser.com) when a tool publishes a new release. Do not edit them here, because the next release will overwrite your changes. Open issues and pull requests in the tool's own repository instead.
